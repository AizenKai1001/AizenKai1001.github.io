# Public project coverage

The archive was assembled by reviewing project manifests, READMEs, implementation
files, vault notes and relevant recorded work. Duplicate worktrees, upstream
clones, backup copies, private data and deployment-only folders were grouped
rather than presented as additional authored projects.

The detailed machine inventory stays in private local notes. This public summary
contains only the project identities and relationships used by the website.

## Archive structure

- `src/content.js` contains the six featured experiments: Distinction AI, DOOMFLY
  experiments, ForgeLab, Plasticity Bench, EvoForge and ForgeGrad.
- `src/catalog.js` contains the wider software/research archive and incorporates
  the historical records and lab records listed below.
- `src/archive-additions.js` contains the archived physics engine, TryNum1 co-op
  shooter, Weapon MM Combo sandbox and media-library automation.
- `src/lab-projects.js` contains the Homelab Platform, Pico Audio Lab and Homelab
  Network Observability records.

The rendered catalog currently has 39 entries, each with implementation scope,
source provenance and credit. Counts displayed by the website are calculated
from the actual data rather than separately maintained marketing figures.

## Historical and collaborative records

The physics-engine build log explicitly records deletion of the code. Its page
is an archived study, with no current executable or service implied. TryNum1
credits collaborator `hewneuroo` alongside the local contribution. Epic's Game
Animation Sample systems and external animations are distinguished from custom
combat, inventory and integration work. Unresolved third-party assets are not
republished as original artwork.

The media-library record uses the later completed workflow notes, which record
dynamic input, staged file completion, library handoff and browser cleanup.
Operational URLs, credentials and storage locations remain excluded.

## Publication boundary

Bot service marketing remains retired. Account exports, captured private data,
device-setup material, backups, credentials and local service configurations are
not included in the public catalog or release. Raw project code and research
datasets remain separate unless a public source is explicitly linked.

The public repository includes buildable website source, selected safe evidence,
and provenance summaries. Machine-specific internal review paths are unnecessary
for those purposes and are not distributed.
