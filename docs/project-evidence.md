# Featured experiment evidence

This public provenance summary describes the records behind the six featured
experiments. Original workspace locations and internal operating notes are
retained privately; they are not needed to build or read this portfolio.

| Experiment | Reviewed evidence | Public scope |
| --- | --- | --- |
| Distinction AI | Project README, `benchmark.json`, `controls.json`, checkpoint-continuation verification and release review | A bounded executable-program learner over engineered visual measurements. The recorded five-seed held-out result was 480/480, compared with an always-no-motion baseline of 347/480. Removing the contact feature changes the result; this is not autonomous perception. |
| DOOMFLY experiments | Upstream/local README, sensory and runtime implementation notes, plasticity validation records | Local experiments and engineering around nftechie's upstream DOOMFLY project. The documented learning candidate failed its visual, conditioning and survival gates. Changed weights are not presented as demonstrated learning. |
| ForgeLab | Build log, strict-energy audit, disabled-motor controls and corrected-solver results | Custom neuroevolution/simulation work. Previously reported walking did not survive the solver correction. A single fresh re-evolution seed remains a limited result. |
| Plasticity Bench | `results-long.json`, matched-seed comparisons and the measured-result note | Three-condition, 400-task Adam/permuted regression run. Internal degradation appeared, but ordinary backpropagation improved on later tasks. This does not refute the larger published plasticity study. |
| EvoForge | Build log, population/plasticity instrumentation and the 14-run controlled sweep | Persistent artificial-life implementation. The recorded plasticity-on/off sweep did not establish a fitness separation, and an age comparison was confounded by survivorship. |
| ForgeGrad | README, operation-gradient checks, neural-training checks and the explanatory note | Educational autograd and training framework. Twenty operations were compared against PyTorch, and a small fixed-batch memorization path was recorded; general language competence is not claimed. |

## Public evidence files

`public/evidence/distinction.json` and `public/evidence/plasticity.json` contain
selected numerical fields and source basenames. They deliberately omit local
paths, operating details, and credentials. Build validation compares the
headline figures and the plasticity chart to these committed exports.

`scripts/export-evidence.mjs` can refresh the exports from three explicitly
supplied input files. It is optional: the site build and CI do not need access
to the original experiments or the private research vault.

## Images and source relationships

Image origins, crops, recorded versions and ownership are documented in
`docs/asset-provenance.md`. DOOMFLY's game image is an attributed upstream asset.
The portfolio's procedural illustrations are labeled separately from actual
project captures and measurements.

`src/credits.js` provides each experiment's upstream/library/paper attribution.
The corresponding public page explains the relationship rather than claiming
authorship of a method, dataset, framework or third-party artwork.

## Review boundaries

Recorded research results were inspected, not regenerated by rerunning the
training experiments for the website. Software tests are not independent
scientific replication. Historical and negative results remain visible, and
planned capabilities are separate from implemented components.
