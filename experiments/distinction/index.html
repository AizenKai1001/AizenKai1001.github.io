Distinction AI

Can a system learn a rule, then change its mind?

  • Python
  • Program synthesis
  • Custom runtime
Recorded prototype dashboard · cropped ↗
EXPERIMENT NOTES

Five training seeds · engineered visual measurements

REVIEWED

September 15, 2026

Sources & credit ↗Discuss this work ↗

Distinction explores learning without a neural network or pretrained model. Its hypotheses are small executable Boolean programs. A prediction is recorded before an action happens, and a wrong prediction can change the program selected by the learner.

The experiment

In a controlled 16 × 16 RGB world, an agent observes an object and a neutral mark, chooses to wait or push, then observes motion. Touching and disconnected marks have the same pixel count, so the task calls for a spatial measurement. Training and frozen evaluation use different body shapes and color palettes.

What I built

A bounded hypothesis search, expression interpreter, counterexample-driven revision, named definitions, and a read-only visual dashboard. The runtime saves its random state and learned programs in integrity-checked checkpoints, allowing continuation to be compared with an uninterrupted run.

What the first run showed

The recorded five-seed benchmark predicted 480 of 480 held-out visual actions correctly. An always-no-motion baseline scored 347 of 480. In a separate cue-memory task, supplying one earlier observation produced 320 of 320 correct predictions, compared with 160 of 320 without it. The release also passed 98 software tests on Windows and Linux.

The important limit

Segmentation, contact measurements, the expression grammar, and the motion target are engineered. Removing the contact measurement reduced matched-scene accuracy to 75%. These results establish learning over supplied features inside a tiny generator; they do not establish autonomous perception or general intelligence.

The next question

Can the learner discover a useful perceptual test rather than receive it? That is a research direction, separate from the capabilities already implemented.
