THE PROJECT

A small language-model learning project that owns its byte-level BPE tokenizer, weight-tied recurrent-depth GPT, data pipeline, training loop, sampling, retrieval experiments, and ablations instead of starting from pretrained weights. The central experiment reuses one core block for multiple passes so inference-time loop count can trade additional compute for effective depth.
