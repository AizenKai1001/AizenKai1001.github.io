THE PROJECT

A compact CUDA roofline-style probe for measuring achievable device-memory bandwidth with read-only reduction, copy, and vector-add traffic shapes. It reports device properties, theoretical bandwidth, timed kernel throughput, and percent-of-peak using CUDA events, providing a concrete hardware baseline for reasoning about memory-bound local AI and graphics workloads.

What exists

The repository contains a build helper and one CUDA probe with warmups, CUDA-event timing, vectorized float4 traffic, and three memory-access shapes.

Current limit

This is intentionally a microbenchmark. One set of bandwidth kernels does not characterize compute throughput, cache behavior, tensor cores, or application-level performance.
